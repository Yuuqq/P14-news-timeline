## 🎓 教学使用说明

> 本工具是《新闻传播AI应用教程》（中国人民大学出版社）配套在线实验平台工具，属于**篇Ⅲ 实操篇 · 第10章 数据新闻可视化实践**（教材 Tier 1 实验工具）。教材命名："交互式突发新闻时间轴"。

**学习目标**：掌握用时间线组织突发新闻事件的叙事方法，能把零散事件整理为按时间排序、重点突出的可视化时间轴。

**核心术语**：时间线（Timeline）、突发新闻（Breaking News）、结构化数据（Structured Data）

**适合对象**：新闻传播专业学生、数据新闻初学者、媒体从业者

**课前准备**：选定一个突发新闻选题并准备 6-8 条事件信息（时间、标题、描述，可摘自公开报道）；本工具打开即用、离线可用。

**课堂流程建议（40 分钟，符合教材"单工具课堂可完成"标准）**
1. **演示导入**（8 分钟）：教师现场录入某突发事件 3-4 条事件数据，演示时间自动排序与颜色标注如何把零散信息变成读者一眼能看懂的事件脉络
2. **上手实操**（20 分钟）：学生自选一个突发事件，整理 6-8 条事件后逐条录入工具（时间+标题+描述），用不同颜色标注关键转折节点，核对时间排序是否正确，最后用"导出 PNG"保存作品
3. **小组讨论**（8 分钟）：时间线按时间排序呈现，但时间先后不等于因果先后——哪些信息适合放进时间线，哪些必须留在正文交代？
4. **总结**（4 分钟）：时间线用结构化事件条目搭起"何时发生"的叙事骨架，取舍事件比录入事件更见编辑功力。

**课后作业**：为本周一条持续进展的新闻制作含 10 条事件的时间轴，导出 PNG 并附 200 字事件取舍说明。

**评价建议**：实操完成度 40% · 分析深度 40% · 反思质量 20%

> 🔒 本工具所有数据仅在浏览器本地处理，课堂与机房环境可放心使用（支持离线）。

## ✨ 功能特性

- 🌗 暗色/亮色模式一键切换
- 🔍 `Ctrl+K` 跨工具搜索跳转
- 📱 PWA 离线支持（可安装到桌面/手机）
- ♿ 完整无障碍标签（aria-label）
- 🔒 所有数据仅在浏览器本地处理

## 🛠️ 技术栈

- 纯 HTML + CSS + JavaScript（零依赖框架）
- CSS 变量设计令牌系统
- Service Worker 缓存策略

- `export-png.js` — 📸 PNG 导出
