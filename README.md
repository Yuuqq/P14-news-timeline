## 🚀 在线体验

**[https://yuuqq.github.io/P14-news-timeline/](https://yuuqq.github.io/P14-news-timeline/)**

支持安装为 PWA 应用，离线使用。

## ✨ 功能特性

- 📱 PWA 离线支持（可安装到桌面/手机）
- ♿ 完整无障碍标签（aria-label）
- 🔒 所有数据仅在浏览器本地处理

## 🛠️ 技术栈

- 纯 HTML + CSS + JavaScript（零依赖框架）
- CSS 变量设计令牌系统
- Service Worker 缓存策略

## 📦 共享模块

- `sw.js` — 📱 PWA Service Worker
- `pm-metrics.js` — 📊 使用量遥测

## 📄 许可

本项目为新闻素养教学工具，仅供学习与研究使用。
